# Architecture

## 分层

```text
┌──────────────────────────────────────────────────────────────┐
│  Clients / SDK / OpenAI-compatible callers                   │
└──────────────────────────────┬───────────────────────────────┘
                               │ Bearer Key
┌──────────────────────────────▼───────────────────────────────┐
│  Pool API: auth / quota / job queue / result serving          │
└───────────────┬──────────────────────────────┬───────────────┘
                │ lease                        │ result
┌───────────────▼──────────────┐  ┌────────────▼──────────────┐
│  Worker pool                 │  │  Object / file storage    │
│  browser + protocol + proxy  │  │  mp4 + manifest           │
└───────────────┬──────────────┘  └───────────────────────────┘
                │ account
┌───────────────▼──────────────────────────────────────────────┐
│  Account pool: credits / cooldown / locks / health            │
└───────────────▲──────────────────────────────────────────────┘
                │ register / claim
┌───────────────┴──────────────────────────────────────────────┐
│  Farm + SMS gate + VMAX toolkit                              │
└──────────────────────────────────────────────────────────────┘
```

## 关键约束

- 账号维度锁：同一 UID 同一时间只允许一个任务占用。
- 任务租约：worker 领取后必须心跳；超时由 stale guard 回收。
- 积分前置检查：30s/1080p 至少预留 120 分，避免扣费后合成失败。
- 质量门：分辨率、帧数、时长、水印四项全部通过才算完成。
- 失败分类：余额不足换号；网络/上游错误重试；质量失败重跑。

## 安全边界

- 控制面、worker、农场、接码分进程部署。
- 管理端只开内网或 VPN；公网只暴露 API 与下载端点。
- 所有密钥通过环境变量注入；仓库不保存任何真实凭据。
